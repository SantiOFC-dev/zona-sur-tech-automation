# Zona Sur Tech - Office Automation Platform

## Overview

This repository contains a collection of systems and tools developed to automate business processes (Office Automation), including billing systems, CRM-like modules, dashboards, and real-time communication tools.

The goal is to centralize operations and reduce manual workload using APIs, automation flows, and cloud infrastructure.
